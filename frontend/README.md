# 24goods frontend (MVP-0)

Two static single-page apps plus a shared TypeScript package, built with Vite and served by Caddy.
There is no SSR and no Node server at runtime.

| Path | What | Stack | Served at |
|---|---|---|---|
| `apps/web` | Buyer app, mobile-first | Vue 3, Vant 4 (on-demand), vue-router, vue-i18n, Pinia | `/` |
| `apps/admin` | Staff/admin console, desktop-first and tablet-usable | Vue 3, Element Plus (on-demand), vue-router, vue-i18n, Pinia | `/admin/` |
| `packages/shared` | API client, contract types, SSE client, formatting, i18n bundles, media helpers, chat components | TypeScript + Vue SFCs | consumed as source |

The API contract is [`../docs/api-contract.md`](../docs/api-contract.md). The types in
`packages/shared/src/types.ts` are a copy of it, so change both in the same PR.

## Requirements

- Node `^20.19` or `>=22.12` (CI uses Node 22 LTS)
- pnpm 12 (`packageManager` is pinned in `package.json`; `corepack enable` works too)

## Commands

Run these from `frontend/`:

```bash
pnpm install --frozen-lockfile

pnpm dev:web          # http://localhost:5173/        (proxies /api → 127.0.0.1:18000, /mockpay → $VITE_MOCKPAY or the same)
# full stack with backend + DB: ../scripts/dev.sh up  (docs/dev-setup.md)
pnpm dev:admin        # http://localhost:5174/admin/  (same proxy)
VITE_BACKEND=http://127.0.0.1:9000 pnpm dev:web   # point the proxy at another backend

pnpm typecheck        # vue-tsc for every package
pnpm test             # vitest for every package
pnpm lint             # policy lint: no v-html/innerHTML, no CDNs/Google assets, no console.log, no eval
pnpm build            # builds shared → web → admin one at a time, then runs the size check
pnpm size             # gzip size of the web app's initial JS (entry + static imports), budget 150 KB
```

On small machines (about 500 MB of free RAM), build each app on its own:

```bash
NODE_OPTIONS=--max-old-space-size=700 pnpm build:web
NODE_OPTIONS=--max-old-space-size=700 pnpm build:admin
```

Build output goes to `apps/web/dist` and `apps/admin/dist`. Caddy serves them as static files with an
SPA fallback:

```
handle_path /admin/* { root * /srv/admin; try_files {path} /index.html; file_server }
handle /api/*        { reverse_proxy api:8000 }
handle               { root * /srv/web;   try_files {path} /index.html; file_server }
```

Cache `assets/*` (hashed names) as immutable. Do not cache `index.html`.

### Suggested CSP

```
default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline';
img-src 'self' data: blob:; media-src 'self' blob:; font-src 'self' data:;
connect-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'self'
```

- `font-src data:` is needed because Vant inlines its icon font.
- `blob:` is needed for local previews of images and voice clips while they upload.
- Nothing is loaded from a third-party origin.

## Structure

```
packages/shared/src
  api/client.ts        fetch wrapper: same-origin credentials, X-Requested-With: fetch on every call,
                       Accept-Language, JSON error envelope → ApiError{code,message,status}, global 401 hook
  api/endpoints.ts     typed buyer + admin endpoint functions, safePayUrl / safeRedirect
  api/errors.ts        error codes, status → code fallback, i18n key mapping
  realtime/sse.ts      RealtimeClient: EventSource with exponential backoff + jitter; after 2 failures it
                       polls every 4 s (callers fetch messages?after_id) until SSE reopens, then resyncs
  format.ts            Intl money/date/relative/countdown formatting; exact money math in integer minor units
  media/voice.ts       MediaRecorder helper (webm/opus, mp4 fallback for iOS, max 60 s, min 0.8 s)
  media/image.ts       canvas downscale to ≤2048 px before upload
  chat/                useConversation (paging, catch-up, optimistic send with client_msg_id + retry),
                       message renderers shared by both apps (text, image, voice, product/quote/order cards, system)
  i18n/                shared en + zh-CN bundles (common strings, error codes, statuses, chat)
apps/web/src
  pages/               Home, Search, Product, Chat, Messages, Orders, OrderDetail, Me, Login, Register
  components/          ProductCard/Grid, SupportPill, TabBar, ChatComposer (text / image / hold-to-talk + tap-to-record)
  stores/              auth, realtime (one SSE per tab + event bus), conversations (unread badge), support status
  styles/tokens.css    design tokens (CSS variables) + Vant theme overrides
apps/admin/src
  layouts/AdminLayout  sidebar (role-aware), top bar (agent status, language, notifications, user menu)
  pages/               Dashboard, Inbox (3-pane CS console), Orders (+ drawer actions), Products (+ dialog),
                       Inventory (admin), Ledger (admin), Audit (admin), Login
```

`src/components.d.ts` and `src/auto-imports.d.ts` in the apps are generated by
`unplugin-vue-components` and `unplugin-auto-import` during `vite`/`vite build`. They are committed so
that `pnpm typecheck` works on a clean checkout. Rebuild and commit them after you use a new Vant or
Element Plus component.

## i18n

- `en` is the source locale and `zh-CN` is required.
- Every bundle has a parity test: same keys, no empty strings, same placeholders, no raw `@`. Each
  merged message is also compiled with vue-i18n.
- Write a literal `@` as `{'@'}`.
- The locale is kept in `localStorage['24goods.locale']`, which both apps share.
- API calls send `Accept-Language`.
- Errors are translated through `errors.<code>`.

## Security notes

- User content is only rendered as text (`{{ }}`). The lint script rejects `v-html` and `innerHTML`.
- The client never sends prices. Buy-now sends `{product_id, qty}`, and quotes are accepted by id.
- `pay_url` must be http(s) before the app navigates to it.
- Login `?redirect=` only accepts same-app paths, so `//evil` is rejected.
- Revealed card codes stay in component memory only, and are cleared on "Hide" and on unmount.
  Inventory import clears the textarea after the server seals the codes.
- No third-party CDN, font or analytics. All assets are bundled.
